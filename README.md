
# 🛠️ ПНД Таймер (HDPE Welding Timer)

Мобильное приложение-помощник для сварщиков полиэтиленовых труб (ПНД). Рассчитывает параметры сварки, ведет пошаговый таймер и сохраняет журнал стыков. 

Приложение создано специально для работы в суровых полевых условиях: оно работает полностью офлайн, имеет громкий звуковой сигнал, который пробивает шум инструмента, а таймер не останавливается, даже если экран телефона погас.

## ✨ Основные возможности
- **Расчёт параметров:** Нагрев, техпауза, осадка и охлаждение рассчитываются по стандарту DVS 2207-1 (ISO 21307) с учётом температуры окружающей среды (доступно 3 диапазона: ≤15°C, 15–25°C, 25–40°C).
- **Громкий сигнал:** Специальный 5-секундный сигнал (с использованием квадратной волны и компрессора) для шумных объектов (90-110 дБ).
- **Фоновый таймер:** Фаза охлаждения (самая долгая) вынесена в нативный Foreground Service. Таймер продолжает идти при выключенном экране.
- **Автоматический журнал:** При завершении полного цикла сварки запись автоматически сохраняется в память телефона.
- **Современный UI:** Минималистичный дизайн в стиле системных часов Android (Material You) с круговым прогресс-баром.

## 🚀 История изменений (Changelog)

### v1.3 (Текущая версия)
- **Нативный таймер:** Добавлен плагин `capacitor-timer-notification`. Фаза охлаждения теперь работает через системный Android-сервис. Таймер больше не замедляется и не останавливается при выключении экрана.
- **Исправление звука:** Пофикшена проблема, когда звук пропадал после сворачивания приложения. Добавлена принудительная «разблокировка» аудио-контекста.
- **Автосохранение:** Убрано всплывающее окно подтверждения в конце сварки. Теперь журнал ведется автоматически, а пользователь видит уведомление (тост).

### v1.2 (Редизайн и Звук)
- **Полный редизайн интерфейса:** Переход на светлую тему в стиле Google Material You (как в приложении «Часы» на Android). Добавлен круговой SVG-прогресс-бар и колесики выбора диаметра/SDR.
- **Мощный звук:** Звук окончания таймера переписан на Web Audio API. Теперь это 5-секундный сигнал с квадратной волной, низкочастотным гулом и компрессором (чтобы пробивать шум).
- **Иконка и заставка:** Сгенерированы кастомные иконки и Splash Screen с помощью `@capacitor/assets`.

### v1.1 (Нативная сборка)
- **Переход на Android:** PWA-приложение упаковано в нативный APK с помощью Capacitor и Android Studio.
- **Release-сборка:** Настроен Keystore, собирается релизный APK (`app-release.apk`).
- **Wake Lock:** Добавлена блокировка засыпания экрана во время активной сварки.

### v1.0 (Первая версия)
- Реализована базовая логика таймера (нагрев, техпауза, осадка, охлаждение).
- Написана математика расчёта толщины стенки и времени по DVS 2207-1.
- Создана первая веб-версия (PWA) с развёртыванием на GitHub Pages.

## 🛠️ Стек технологий
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Web Audio API, SVG).
- **Native Bridge:** Capacitor 6.
- **Android:** Android Studio, Java/Kotlin (для плагинов).
- **Хранение данных:** LocalStorage.
